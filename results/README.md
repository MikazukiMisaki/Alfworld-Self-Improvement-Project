# Historical Result Archive

This directory contains historical Sprint 1, smoke, and diagnostic artifacts.
They are retained in place to preserve Git history. Their presence does not
prove that they were generated by the current environment, and they must not be
used as training or comparison inputs without explicit provenance validation.

New runtime output belongs under ignored `artifacts/runtime/`. New files under
`results/` are ignored to prevent accidental recommit of experiment output.
See `reports/result_provenance.json` for content-based classifications.
