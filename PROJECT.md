# Alfworld-Self-Improvement

This repository supports a master's thesis on recovery-aware intervention
selection for small language agents.

Sprint 1 is intentionally limited to a reproducible ALFWorld baseline:

ALFWorld → Qwen3-8B → trajectory collection → evaluation → JSONL artifacts.

It does not include reflection, memory, intervention selection, DPO, PPO, or
GRPO. Those are research stages that begin only after the baseline is stable.
