# Sprint Roadmap

## Sprint 1 — Reproducible baseline

Deliver an ALFWorld/Qwen3-8B collection pipeline that writes canonical
trajectories, metrics, and a run manifest.

## Sprint 2 — Paired trajectory data

Collect continue-versus-recovery branches for intervention-value labels. No
selector is introduced until branch data is audited.

## Sprint 3 — Fixed recovery study

Test one frozen recovery operator against no-recovery, unconditional, random,
and entropy baselines.

## Sprint 4 — Recovery-aware selection

Train and evaluate a selector only if recovery value is heterogeneous and
predictable on held-out development tasks.

## Sprint 5 — Final evaluation

Run fixed, cost-matched valid_seen and valid_unseen comparisons and prepare the
paper evidence.
