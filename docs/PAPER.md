# Paper Direction

## Working title

When Should Small Language Agents Spend Extra Reasoning? Recovery-Aware
Intervention Selection in ALFWorld

## Research question

Can a small language agent predict which states gain enough value from one
fixed recovery action to justify its additional reasoning cost?

Sprint 1 establishes the control condition: a reproducible, action-grounded
Qwen3-8B ALFWorld baseline. It makes no self-improvement claim.
